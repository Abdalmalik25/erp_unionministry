# حوكمة المحتوى — المنظومة الوطنية لإدارة قطاع العمل

## المصدر الوحيد للمحتوى المؤسسي

كل نصوص التعريف الرسمية تعيش في ملف واحد: `src/app/content/institutional.ts`.
يستهلكه الموقع العام ولوحة الوزارة الداخلية معاً. أي تعديل محتوى يُتم فيه فقط.

| التصدير | الغرض | مستهلكوه |
|---|---|---|
| `NATIONAL_REGISTRIES` | السجلات الوطنية العشرة | صفحة «عن»، السجلات، دليل المنظومة، بوابة الوزارة (شارات) |
| `LEGAL_ITEMS` | المرجع القانوني الكامل | الصفحة القانونية، دليل المنظومة |
| `FAQ_ITEMS` | الأسئلة الشائعة | صفحة الأسئلة، دليل المنظومة |
| `NATIONAL_PANELS` | لوحات المؤشرات الوطنية الست | الرئيسية العامة + ترويسة بوابة الوزارة |
| `IMPACT_ITEMS` | الأثر الوطني الأربعة | الرئيسية العامة |
| `VISION_COMMITMENTS` | التعهدات المؤسسية | صفحة «عن» |
| `GOVERNANCE_PRINCIPLES` | مبادئ الحوكمة الملزِمة | الرئيسية العامة (الأيقونات تُربط في المكوّن) |
| `GUARANTEE_ITEMS` | الضمانات الحكومية الثابتة | صفحة «عن» + بوابة الوزارة |

قاعدة الاختبار (`institutional.test.ts`) تفرض اكتمال كل مجموعة وتمنع التكرار
وتضمن أن كل نص نظامي يُستشهد به في الأسئلة له مدخل في المرجع القانوني.

## الاسم الرسمي الموحد

- **الاسم الكامل**: «المنظومة الوطنية لإدارة قطاع العمل»
- **المختصر**: «المنظومة الوطنية»
- **التسمية الدولية**: National Labour Sector Management Platform (NLSMP)
  - إملاء بريطاني «Labour» وفق عرف اليمن ومنظمة العمل الدولية.
  - تُعتمد في المراسلات الدولية فقط؛ العربية هي أساس كل الواجهات.
  - مواضعها: `BRAND.nameEn / BRAND.abbrEn` + `system_settings.system_name_en` + `/api/system/branding` (systemNameEn) + سطر شاشة الدخول + صفحة «عن».

مواضع الاسم (لا يجوز تعدد المصادر):
1. قاعدة البيانات: `system_settings.setting_key = 'system_name_ar'` — المصدر الأول لشاشة الدخول عبر `/api/system/branding`
2. `src/app/branding.ts` → `BRAND.systemName / BRAND.systemShort`
3. البدائل الصلبة في `server/routes/system.js`
4. `index.html` (العنوان والوصف) و`public/manifest.json`

معرفات الكود الداخلية (`UnionSphereDB`, `unionsphere-*`) ليست ظاهرة للمستخدم ولا تُغيَّر.

## الهوية البصرية — قاعدة الشعارين

| الرمز | الملف | الاستخدام الحصري |
|---|---|---|
| **شعار المنظومة** | `public/favicon.ico` (`BRAND.markUrl`) | كل الواجهات: أشرطة التطبيق، الترويسة والتذييل العامان، شاشة الافتتاح، وأيقونات الأجهزة كلها |
| **الطير الجمهوري** | `public/logo_yemen.jpg` (`BRAND.emblemUrl`) | المستندات والتقارير (محاضر التفتيش، محاضر النزاعات، مدير الطباعة) + الشاشة الرئيسية لكل بوابة (شاشة الدخول) |

التطبيق عبر `<BrandLogo variant="mark" />` (الافتراضي) أو `variant="emblem"` — لا يُستخدم `logo_yemen.jpg` مباشرة في أي مكوّن.

## الأيقونات الرسمية

مولدة من **شعار المنظومة** (إطار 48px من `favicon.ico`) على بلاطة الهوية `#0f1c31` مع إطار رفيع:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-brand-icons.ps1
```

- يعيد توليد الطقم كاملاً (512/192/180/32/16) ولا يمس `favicon.ico` نفسه (المصدر الرسمي).
- النسر ممنوع في أي أيقونة مهما كان الحجم.
- بعد أي تغيير يُرفع `CACHE_VERSION` في `public/sw.js` لإجمال تحديث الأجهزة.

## قاعدة ترميز حرجة (درس موثق)

**يُمنع** استخدام `Get-Content -Raw` ثم `Set-Content` على أي ملف يحوي عربية:
PowerShell 5.1 يقرأ UTF-8 بترميز ويندوز فتشوّه الملف ويُنشر تالفاً.
البديل الآمن دائماً:

```powershell
$c = [System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)
[System.IO.File]::WriteAllText($path, $c, [System.Text.Encoding]::UTF8)
```

أو أداة Edit / سكربت Node. عند الشك: `scripts/repair-mojibake.mjs` يستعيد
آخر نسخة سليمة من git ويعيد تطبيق الاستبدالات بترميز صحيح.
