# منصة UnionSphere 🏢

## نظام إدارة المنظمات النقابية المتكامل

منصة ويب احترافية مؤسسية متكاملة لوزارة الشؤون الاجتماعية والعمل، مصممة لإدارة المنظمات النقابية (النقابات والاتحادات) وأعضائها وأنشطتها وحساباتها المالية وخدماتها، مع نظام أدوار مزدوج (وزارة + منظمات نقابية).

---

## 🎯 الميزات الرئيسية

### 1. نظام المصادقة والصلاحيات
- ✅ تسجيل دخول موحد مع Supabase Auth
- ✅ أدوار متعددة (وزارة ومنظمة نقابية)
- ✅ Protected Routes لحماية المسارات
- ✅ إدارة الجلسات بشكل آمن

### 2. لوحات التحكم التفاعلية

### 7. نظام الوثائق مع دورة مستندية

### 9. المخالفات والقوائم السوداء
- تسجيل المخالفات
- إدارة القوائم السوداء
- طلبات رفع المخالفات

### 10. التقارير الديناميكية

### 11. سجل التدقيق (Audit Log)

## 📦 التثبيت والإعداد

### المتطلبات
- Node.js 18+
- pnpm (مدير الحزم)
- حساب Supabase

### خطوات التثبيت

1. **تثبيت الحزم**
```bash
pnpm install
```

2. **إعداد Supabase**
   - قم بإنشاء مشروع على [Supabase](https://supabase.com)
   - انسخ Project URL و Anon Key
   - اتصل بـ Supabase من خلال المنصة

3. **تشغيل المشروع**
```bash
pnpm dev
```

4. **إضافة البيانات الأولية (اختياري)**
أرسل طلب POST إلى:
```
https://<project-id>.supabase.co/functions/v1/make-server-c73879ee/init-data
```

## 🔐 الأمان

### ميزات الأمان المُطبقة

1. **Protected Routes**
   - جميع المسارات محمية بـ `ProtectedRoute`
   - التحقق من الصلاحيات قبل الوصول

2. **Validation شامل**
   - التحقق من جميع المدخلات
   - التحقق من الرقم الوطني اليمني
   - التحقق من قوة كلمة المرور
   - Sanitization للبيانات

3. **Authentication**
   - Supabase Auth للمصادقة
   - JWT Tokens للجلسات
   - Auto logout عند انتهاء الجلسة

4. **Error Handling**
   - معالجة الأخطاء في جميع API calls
   - رسائل خطأ واضحة للمستخدم
   - Logging للأخطاء

## 🔧 التطوير

### هيكل المشروع
```
src/
├── app/
│   ├── components/      # المكونات القابلة لإعادة الاستخدام
│   │   ├── ui/         # Button, Card, Input, Modal, Toast
│   │   └── layouts/    # RootLayout
│   ├── contexts/       # AuthContext
│   ├── hooks/          # useApi, useUnions, useMembers
│   ├── pages/          # صفحات التطبيق
│   │   ├── ministry/   # صفحات الوزارة
│   │   ├── organization/ # صفحات المنظمة
│   │   └── Login.tsx   # صفحة تسجيل الدخول
│   ├── utils/          # validation, colors
│   └── routes.tsx      # تعريف المسارات
├── styles/             # ملفات CSS
└── supabase/           # Backend Functions
    └── functions/
        └── server/     # API Endpoints
```

### إضافة صفحة جديدة
1. أنشئ ملف في `pages/`
2. أضف المسار في `routes.tsx`
3. أضف رابط في Sidebar إذا لزم الأمر

### إضافة API Endpoint
1. أضف route في `supabase/functions/server/index.tsx`
2. أنشئ custom hook في `hooks/useApi.ts`
3. استخدم الـ hook في الصفحة
