## 📁 بنية المشروع

```

├── app/
│   ├── components/           # مكوّنات واجهة المستخدم
│   ├── contexts/            # سياقات التطبيق
│   ├── middleware/          # الوسيطات الأمانية
│   ├── pages/              # الصفحات
│   ├── types/              # تعريفات TypeScript
│   │   ├── entity.ts       # كيانات المنظمات النقابية
```

##  إعداد سريع

```bash
# تثبيت
pnpm install

# تطوير
pnpm run dev

# بناء للإنتاج
pnpm run build

# فحص صحة النظام
pnpm run health-check

# إنشاء نسخة احتياطية
pnpm run backup
```
