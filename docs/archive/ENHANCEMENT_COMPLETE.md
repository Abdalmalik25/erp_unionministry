## 🚀 خطوات النشر

```bash
# 1. تثبيت الاعتماديات

# 2. بناء المشروع
pnpm run build

# 3. اختبار البناء
pnpm run preview

# 4. نشر الوظائف (إذا كان Supabase متصل)
supabase functions deploy entities-api
```
